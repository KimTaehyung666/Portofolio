# Portofolio Muhammad Rival

Portofolio frontend developer & desainer (React + Vite + TypeScript).

## Menjalankan

```bash
pnpm install
pnpm dev
```

## Sebelum deploy

- Taruh foto di `public/portrait.png`
- Cek email di bagian kontak (`src/App.tsx`)
- Deploy ke Vercel: build `pnpm build`, output `dist`
